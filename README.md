# 📊 War Monitor — ایران / اسرائیل / آمریکا

مانیتور خودکار وضعیت جنگی بر اساس فیدهای RSS چندزبانه.

## اجرا

```
python monitor.py        # جمع‌آوری خبر + نرخ ارز + گزارش کامل
python monitor.py fx     # فقط نرخ لحظه‌ای دلار (برای اجرای هر دقیقه)
```

خروجی:
- `digest.txt` — گزارش فارسی (نرخ ارز، وضعیت، آمار، عناوین با لینک)
- `items.jsonl` — تاریخچه کامل خبرها (JSON per line)
- `state.json` — خبرهای دیده‌شده (برای جلوگیری از تکرار بین اجراها)
- `fx.jsonl` — تاریخچه نرخ ارز (هر نوبت یک خط)

### جمع‌آوری در غیاب کاربر
اگه چند ساعت اجرا نشه، اجرای بعدی همه خبرهای اون فاصله رو می‌گیره و
در ابتدای گزارش با عنوان `📥` گروه‌بندی بر اساس ساعت نشون می‌ده
(تست‌شده با سناریوی ۶ ساعت خاموشی).
ضمناً `state.json` اگه پاک بشه هم خبر تکراری نمی‌خوره، چون
`items.jsonl` هم مبنای «دیده‌شده» هست.

## منطق فیلتر

1. **حذف منابع وابسته** (بالا) — قبل از هر چیز.
2. **مرتبط بودن:** عنوان باید یکی از طرف‌های درگیری (اسرائیل، ایران، حزب‌الله،
   پنتاگون، غزه، لبنان، تنگه هرمز…) رو داشته باشه — یا «ایران» + یک اصطلاح
   درگیری (جنگ/حمله/موشک/تحریم/هسته‌ای).
3. **نویز:** ورزش، انتخابات، یادداشت/سرمقاله حذف می‌شن.
4. **دسته‌بندی:** نظامی / دیپلماسی / هسته‌ای / تحریم / انرژی-دریا / عمومی.
5. **حذف تکرار:** از روی عنوان نرمال‌شده (منبع انتهایی حذف می‌شه).
6. **بازه:** فقط خبرهای ≤۷۲ ساعت؛ وضعیت از بازه ۲۴ ساعته حساب می‌شه.

## سطح وضعیت (هوریستیک روی عناوین — ارزیابی میدانی نیست)

| شرط (خبر «تشدیع‌آمیز» در ۶ ساعت) | وضعیت |
|---|---|
| ≥ ۸ | 🔴 تشدید فعال |
| ۳–۷ | 🟠 تنش بالا |
| ۱–۲ | 🟡 درگیری پراکنده |
| ۰ و در ۲۴ ساعت ≥ ۳ | 🟡 آرام‌نسبی |
| ۰ و در ۲۴ ساعت < ۳ | 🟢 سکوت نسبی |

آستانه‌ها در تابع `status_level()` قابل تغییرن؛
حدسی که «خبر تشدیع‌آمیز» محسوب می‌شه روی `ESCALATION` هست.
